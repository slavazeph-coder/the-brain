# Outreach templates: site-to-sim pilot

Founder-signed and personal: one real detail about the recipient in the first line. Link the published real-room pack
and a 60-second demo, never a claim the claims sheet forbids (no survey-grade, millimetre, native Revit, LOD 300,
manipulation-ready). Replace every `[...]` before sending.

## First email (robot company)

**Subject:** [Robot] fit check for [their customer type] sites, from a phone video

Hi [first name],

Would a fixed-fee pilot on one of your upcoming sites be worth 20 minutes?

## Breakup (day 10)

Last note from me. If pre-deployment site checks are not a problem for [company] right now, no reply needed. If they
are later, the pilot is one site, fixed fee, 48 hours: [link].

## Discovery call (20 minutes)

1. How do you check a new site today? Who does it, how long does it take, what does it cost?
2. What went wrong on the last deployment that a site check would have caught?
3. Which simulator or planner do you use (Isaac Sim, Gazebo, Nav2, in-house)? Which file would you load first?
4. What accuracy would you need, measured how?
5. Who approves a pilot like this, and from which budget?
6. Is there a site in the next 30 days we could do?

Qualified = named budget owner + a real site available within 30 days. Send the SOW the same day.

## Tracking

Log every touch in a sheet with: date, company, person, channel, template, reply (y/n), call booked, proposal sent.
Weekly gates from the [30-day plan](../research/brainsnn-best-next-move-2026-11-24.md): 8 Dec ≥200 touches, ≥3% replies
and ≥3 calls booked; 15 Dec ≥350 touches, ≥8 conversations and ≥2 proposals; 24 Dec ≥1 signed, prepaid pilot.
