The user asked for a professional, cleaner glass style on the existing BrainSNN
GT3 studio at www.brainsnn.com/sponsor/gt3/. Preserve the working first-party
Porsche model, automatic logo placement and the Spot > Logo > Checkout flow.

This presentation-only pass separates the viewer and inspector into two glass
panels, adds a floating navigation surface, restrained cyan/violet ambient
lighting, softer borders, clearer type, an upload icon and consistent glass
review dialog. No new runtime dependencies or third-party requests. Never blur
or overlay the interactive 3D canvas. Opaque fallback, reduced transparency,
reduced motion and higher contrast are included. No JavaScript, backend,
pricing, payment flag, campaign terms, credentials or robot studio are changed.

Local layout previews use the prior rendered car screenshot as an explicitly
internal layout fixture because this environment cannot create WebGL. Do not
present those previews as live rendering evidence. CI and post-deploy glass.mjs
exercise actual first-party geometry, decals, pointer interaction and the review
connection in full Chromium. Post-deploy tests allow GET/HEAD only and never
submit a production design or payment. Physical iPhone performance is not
established by mobile-width browser screenshots.
