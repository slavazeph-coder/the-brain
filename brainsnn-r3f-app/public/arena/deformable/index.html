What this simulation measures

The rope is an inextensible elastic-rod approximation with a prescribed attachment motion. The robot arm shows the kinematically driven attachment chain; it is not a learned whole-body controller.

The pink target is a non-colliding distance judge: the tip reaches it when its swept path comes within the target radius. This does not simulate a balloon breaking. These local MuJoCo results use no trained policy or calibrated DeformX2 model. Physical whip-crack accuracy and hardware performance have not been validated.

Find swing compares 12 prescribed motions and records the best tested motion again. It changes the controller, never the selected target. This bounded search is not policy training.
